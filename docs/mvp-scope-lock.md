# Truthlabel MVP Scope Lock

## Current MVP features

- manual ingredient scan
- barcode lookup
- camera barcode scan
- OCR ingredient label scan
- ingredient intelligence matching
- category rules
- exposureRisk score
- allergy profile
- region settings
- external recall and safety lookup
- result page
- confidence notes
- feedback report

## Explicitly out of scope for this launch

- Better Options
- affiliates
- product recommendations
- user accounts
- saved scan history
- admin dashboard
- native app
- advanced nutrition analysis
- full medical or allergy certification

## Launch rule

Do not add new major features to the launch candidate unless they fix a P0 or P1 issue that blocks real-user MVP testing.
